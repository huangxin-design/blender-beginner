# 可编辑工程与渲染步骤

[scene.blend](scene.blend) 是原项目 v005-4k 的 Pink_Wave.blend，复制时保留了原字节。工程包含模型、材质、灯光、相机和 200 帧循环动画；原说明记录环境灯光贴图已打包，打开时不必另行下载。使用 Blender 5.2.1 LTS 制作。

[render_final.py](render_final.py) 是当时的原始渲染步骤，处理已打开的工程：按 1—200 帧输出 PNG，并另渲染第 201 帧检查接缝。它不负责建模，也不负责最终视频编码；默认跳过同目录 frames 中已经存在的图片。

继续制作时，先让 Codex 建立一个新版本和新的输出目录，再重新渲染，避免把原图和新图混用。脚本会输出原生 3840×3840 图像；设备不同，应先调整渲染后端并做小样。

本次未重新运行渲染脚本或覆盖原工程。已用独立 Blender 进程在仓库新位置重开，关闭自动执行，确认 Studio Small 01 环境灯光已打包、没有链接库；检查前后源文件 SHA256 与原件一致。本次没有重新渲染。
