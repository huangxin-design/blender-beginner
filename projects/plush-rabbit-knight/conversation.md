# 毛绒兔骑士｜制作过程摘要

早期实践资料，未作为当前 Skill v04 的效能验证。摘要取自包内记录，没有原始逐字聊天；[六轮优化提示词](prompts.md) 是事后整理的任务方案，不是已经执行的六轮对话。

1. **制作角色底稿。** 按参考建立兔子、剑、盾、树墩与背景，随后升级毛发、木纹、金属和晶体的原生材质及灯光。
2. **保留原生输出。** 保存可编辑工程、原生 PNG 和线性 EXR。随包盘点记录毛发系统与额外卷曲曲线均保存在工程内。
3. **明确两项精修。** 对用户提供的已有图片进行生成式编辑，集中增强宝剑发光与三朵云的体积，同时加强靠剑侧的暖光。
4. **记录效果与代价。** 既有对照认为剑刃晶面仍可辨、左眼未被辉光遮挡；也记录剑心局部近白、毛发卷曲更明显、草丝略粗。
5. **区分图片与工程。** 此次精修只产出 PNG，没有更新 `.blend`。归档分别提供底稿、原生图、终图与实际提示词，避免把图片新增效果写成已完成的节点修改。
