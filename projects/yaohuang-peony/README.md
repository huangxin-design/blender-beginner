## 从一个花苞开始

这次最关键的反馈是：“完全不一样 你看参考作品 是一个花苞生长的全部效果”。作品随后围绕单朵牡丹从闭合到盛放的连续过程展开，再逐步确认玻璃与金属、发光花蕊、朦胧镜头、半透明枝叶，以及有快有慢的开花节奏。

花朵先缓慢松苞，外瓣较快展开；中段稍作停顿，内瓣再加速打开，最后缓缓停在盛放状态。花瓣使用玻璃、透光与透明材质混合，配合金属细边；叶片、枝干也保留透光质感。景深、薄雾、辉光和轻微镜头效果都保存在工程中。
