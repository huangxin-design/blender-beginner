继续编辑请优先打开各作品页面中的核心工程。本次没有重新执行这些历史脚本或重新渲染作品；它们保留原工作流的输入输出约定，不能视为已验证的一键重建工具。部分报告被脚本当作输入使用，因此一起保留；报告中的检查是历史记录。

公开文本中的历史用户名路径已替换为 `YOUR_USERNAME`，文件清单记录了哪些文本发生变化。重跑前需要在副本中检查路径、依赖、脚本顺序和输出文件，避免覆盖已归档工程。`.blend`、图片和视频保留原文件字节；工程内部仍可能保留历史输出位置或已打包资源的来源标记，见 [源文件检查](../early-works-source-check.md)。
