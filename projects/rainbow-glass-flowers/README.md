# 虹彩磨砂玻璃花 · 前景与景深

三朵大小错落的玻璃花，在粉色背景中缓慢开合。花瓣带乳白半透底色与青、紫、粉、淡金色的边缘反光；右下花位于前景，另外两朵花保留柔焦。

![虹彩玻璃花四镜头横向预览：开场全景、前景花近景、花瓣特写、收尾全景](preview.jpg)

从左到右：开场全景 → 前景花近景 → 虹彩花瓣特写 → 收尾全景。选取成片第 1、97、217、360 帧，保留每格 3:4 比例，横向拼接展示。
