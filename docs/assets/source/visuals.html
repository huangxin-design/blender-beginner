BLENDER 开工助手AI 风格 3D 需求示例

你说“想要什么”，Codex 帮你做出来

你只要说“做一颗 AI 材质球：磨砂玻璃，里面透一点光，
边缘有柔和光晕，背景虚一点。”
磨砂玻璃
粗糙度 + 细微肌理

调柔高光，让表面有细腻的颗粒感。

里面透点光
透射 + 折射率（IOR）

调整透光与折射，必要时混合材质。

边缘有光晕
发光 + 合成光晕

先布置亮部，再加柔和光晕，保住轮廓。

背景虚一点
景深 + 对焦距离 + 光圈

让主体清晰，背景自然失焦。
