# 参考图制作前评估

在用户提供参考图、希望判断能否用 Blender 制作时读取。本文件用于选择可执行方案；评分不是成功率、相似度百分比或效果保证。

## 先确定评估对象

- 必须实际查看参考图，再描述能观察到的内容；不能只依据文件名、用户转述或想象评分。
- 默认目标是「固定一个相机视角的静帧 + 可编辑 `.blend`」。说明这一假设，有已有用途要求则沿用。
- 用户要求自由换视角时，评估完整 3D；单图背面、厚度和遮挡结构需注明推测。正面做得像不能证明完整模型准确。
- 动画另评估运动、绑定、模拟和缓存；3D 打印另评估尺寸、壁厚和封闭几何。原来的静帧分数不能直接沿用。
- 先列 2–4 个决定观感的特征，例如轮廓、反光、材质肌理、光晕范围、前后虚实；每项写清观察证据。
- 分开写「图中看见的」「用户要求的」「为推进而采用的假设」。把图中不可见信息称为假设，不称为已还原。

## 五个维度，每项 0–4 分

评估的是**当前输入、用途、设备和时间条件下，拟定制作方案有多可执行**。对每项给一个短理由，引用具体画面特征、可用素材或已检查的设备条件。

| 维度 | 具体检查什么 |
|---|---|
| 几何与结构 | 轮廓能否拆成可建模部件；结构是否遮挡；是否需要精确人物、毛发、复杂有机形态或运动结构 |
| 材质与肌理 | 颜色、粗糙度、反射、透光和细纹是否可辨；需要程序纹理、贴图还是实际几何；细节在目标尺寸是否重要 |
| 灯光、镜头与后期 | 光源方向、阴影、构图、透视、景深和辉光能否合理解释；关键视觉是否依赖无法从单图确定的效果 |
| 外部素材依赖 | 必需模型、纹理、字体、标志是否已有且可用；缺失素材能否替代；是否影响用户要求的准确性 |
| 设备与制作预算 | 已知硬件、内存或显存、输出尺寸、时限是否支持该方案；是否需要降低采样、分辨率、模拟复杂度 |

涉及 4K、动画或设备卡顿时，按 [设备适配评估](device-assessment.md) 获取证据。设备检测、实际加速后端、目标场景代表帧和等待预算共同支撑本项分数；不能用 Mac/Windows 品牌标签或安装测试的一张立方体代替性能判断。

各维度共用以下刻度，避免凭感觉给小数：

| 分数 | 判断依据 |
|---|---|
| 4 | 输入充分，已有明确制作路径，常规工具和现有资源足够 |
| 3 | 路径明确，需要少量估计与迭代，不影响主要观感或用途 |
| 2 | 存在明显难点；采用写明的简化或补充资料后可推进 |
| 1 | 依赖尚未解决的重要条件，或须大幅简化；现方案不宜直接承诺交付 |
| 0 | 已知条件下无法满足该维度的必要要求，须改变条件或方案 |
| 待查 | 证据不足，无法给出有依据的分数；不默认填中间分 |

总分 = 五项分数之和 × 5，采用整数。相同目标和证据使用相同规则；不因用户希望高分而调整。

- 80–100：适合直接做低成本预览验证。
- 60–75：可做，先说明主要简化和可能差异。
- 40–55：建议先验证最难部分，再决定是否展开完整场景。
- 0–35：现条件下不宜承诺目标效果，先解决必要条件。

**关键阻塞优先于总分。** 任一维度为 0，或存在未满足的不可替代要求，先显示「当前阻塞：……」；即使其他项总分很高，也不能称为可以直接实现。任一维度为 1，结论至少降为「先验证关键条件」。不得把缺失的精确标志、不可见的必要结构、不可行的时限等藏在平均分里。

明确阻塞的是哪项交付要求，不阻止已授权且不依赖该条件的可逆工作。原目标和简化路线分别记录、分别评价；不能用去掉必要品牌、降低输出规格后的高分回答原目标。给一个推荐的下一步，有实质取舍才给备选；分数和路线建议不自动授权开始制作。跨轮衔接按 [项目衔接与反馈](project-loop.md)。

有「待查」项时不给确定总分：已知项之和 × 5 是下界，每个待查项增加 20 分得到上界，标注为「信息未齐的分数范围」，不套用总分档位。例如已知四项共 13 分、硬件待查，只能写 65–85 分；这不是统计置信区间。

## 同时给出置信度

- 高：参考清晰、用途明确、必要素材和运行条件已核验，主要判断还得到相关小样支持。
- 中：主要特征清晰、路径合理，但仍有部分材质、遮挡或性能估计；首次单图评估通常属于此类。
- 低：参考模糊、关键部分不可见、用途或必要条件缺失，结论可能明显变化。

写明置信度的原因与「补充什么会改变判断」。高可实现分数可以同时只有低置信度。试渲染后可修订分数，但要指出哪条新证据改变了判断；不要把最终视觉验收等同于制作前分数。

## 最少缺项处理

- 没有参考图：给出「待评估」，继续已请求的文字分析或翻译，不编造视觉观察或分数；不因此启动环境准备。
- 用途未说：明示固定视角静帧假设继续；涉及动画、精密尺寸或打印的线索时，先澄清影响方案的用途。
- 设备未知：只看图时把预算维度标为待查。已请求本机设备评测或制作时，先确认目标机器并复用适用证据，确有需要才补测；不能自动拿当前主机替代用户另一台设备。时间估计保留待验证部分，不承诺分钟级完成。
- 必要素材缺失：说明准确版本为什么依赖它；能先做占位或简化预览时继续，不能把占位称为最终还原。
- 多处信息不明：一次只问会改变下一步的关键问题；非关键缺项写成假设，不要求新手填写技术问卷。

## 虚构教学例：不代表已查看任何真实参考图

假设用户给的是「白色背景上的磨砂圆柱瓶，暖色侧光，背景有轻微虚化」，只需单张静帧，不要求品牌文字。再假设目标为 960 × 720 预览，已核验本机可运行 Blender，且允许常规迭代。

- 几何 4：主体可由圆柱、瓶肩和瓶盖组成；固定视角下不需要精确推测背面。
- 材质 3：磨砂反光有明确路径，粗糙度与细纹仍需预览调节。
- 灯光与镜头 3：侧光、阴影和虚化可分别控制，但单图无法确定真实灯位和镜头参数。
- 素材 4：这个假设任务不依赖外部标志、字体或专有模型。
- 设备与预算 3：在上述假设的已核验环境内可做预览，最终耗时仍需小样测量。
- 结论：85/100，置信度中；适合先做预览，无已知阻塞。优先验证瓶肩轮廓和磨砂反光，尚不能承诺与参考精确一致。

如果用户改成「透明瓶内液体摇晃的动画」，需要重新评估新任务；不能继续沿用 85 分。
