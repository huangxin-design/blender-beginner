# 封面规范与渲染

使用已确认的 09「极简强对比」：主教学标题最大，末尾关键词为荧光黄反色块；工具条按实际文字宽度留两侧 24px；频道下方有简短广播装饰；底部三个教学点等分、光学居中，采用 01「旧报刊半调」肌理。参考图是 `assets/cover/approved-cover.png`。

固定输出为 1080×1440、3:4，另出 360×480 缩略图。底色强调色为 `#E9FF24`，不重新选择十套方向。标题、作品、工具、副题、三个标签、频道和系列编号均可替换。

## 先选择真实素材模式

### background：已有完整海报

用户已提供包含当前作品的电视海报底图时使用。`background` 必须是 3:4，脚本仅等比归一到输出尺寸并叠加原生排版，不替换里面的作品、不自动裁图。

`assets/cover_example/background_example.json` 用于复现已确认的花朵案例。配套 `flower_poster_example.png` 的花朵已经烘焙在背景里，**不可换个标题就把它当成新案例**；用于新作品时替换整个 `background`。背景来源按用户实际提供的信息描述，不能仅因为画面有电视就声称它是 Blender 原生渲染。

### artwork：把当前作品放进空白电视

只有作品图、还没有完整电视海报时使用。复制 `assets/cover_example/artwork_example.json` 到当前案例目录，把 `artwork` 换成当前作品文件，并同步修改文案。

先查看真实源图，再选择要展示的核心视觉。界面边框、黑边、大面积留白和不影响识别的长柄可裁去；花心、角色头部及关键轮廓应保留。核心尽量占内屏主维度的约 70–90%，作为构图参照而非硬性数值。脚本不自动识别主体，裁切范围由实际画面决定。

未填写 `background` 时使用附带的空白 CRT 背景、共享屏幕几何和曲边遮罩。空白背景来自内置图像生成工具，原花朵已被去除，来源与提示词见 `assets/cover/crt_blank_prompt.txt`。脚本先裁核心区域，再等比放大填满映射平面，透视贴合内屏边缘，保留外侧玻璃和机身。透明作品先放在深色底上。

封面默认 `screen.fit: "cover"`，不采用视频的 `contain` 加模糊补边。只有明确需要保留全幅、且接受主体缩小及模糊补边时才显式设置 `contain`；视频规则不随此修改。

这是 **二维图像合成**，不是重新搭建 Blender 电视场景，也不模拟真实玻璃曲率、透射或场景反射。输出报告会写明这种区别；真实 Blender 工程画面仍来自本次实际工程。新案例不能默认沿用示例花朵。

使用内置电视时，可只覆盖填充方式和裁切位置，共享几何与遮罩会继续生效：

```json
{
  "mode": "artwork",
  "artwork": "media/current_work.png",
  "screen": {
    "fit": "cover",
    "centering": [0.5, 0.5]
  }
}
```

- 顶层 `artwork_crop: [left, top, right, bottom]` 是 **EXIF 方向校正后的源图像素坐标**，先用于选取核心区域，再执行 `cover`。不填则从全图开始；不要把花朵示例的裁切数值套到其他作品。
- `screen.centering` 为两个 0–1 的值，控制 `cover` 剩余裁切在横、纵方向的位置；默认 `[0.5, 0.5]` 居中，0 偏左/上，1 偏右/下。先裁掉无关内容，再用它微调核心位置。
- 自备不同空白电视时，明确配置 `background` 与实测 `screen.quad`，不能套用内置遮罩。`quad` 使用归一后 1080×1440 画面的左上、右上、右下、左下四点；`plane_size` 是映射前画布比例。`corner_radius` 为短边比例，范围 0–0.25。
- 曲边贴合可配置 `screen.mask`：1080×1440 灰度 PNG，白色显示作品，黑色保留背景；路径相对配置文件。遮罩应贴合实际玻璃内缘，源图核心裁切与屏幕几何是两项独立设置。

### 修复旧案例

旧案例可能复制过 `template/scripts/render_cover.py` 和 `screen.json`。升级后调用当前安装目录的渲染器，不继续运行旧本地脚本。确认旧案 `background` 只是同款附带 `crt_blank.png`、`screen` 仍是旧四角时，删除这两个配置项以使用新版内置几何和曲边遮罩；保留真实作品与文案，重新测量 `artwork_crop`。不同电视背景继续使用其自定义几何和遮罩。

## 配置与运行

命令只需要 Pillow。字体查找复用视频渲染器：优先本机抖音美好体、MiSans、Consolas；中文可使用已安装的 Noto Sans CJK/SC、思源黑体或微软雅黑。缺字会报错，不静默使用方框字。包内不包含字体文件。

```sh
python /path/to/huanghuayu-tutorial-video/scripts/render_cover.py --config /path/to/current_case/cover.json --output /path/to/current_case/cover_output
```

配置和素材路径均相对 `cover.json`，与命令所在目录无关。输出必须在本次案例目录，不能写回安装目录或附带示例。

最小新案例配置：

```json
{
  "mode": "artwork",
  "artwork": "media/current_work.png",
  "source_note": "本次工程实际导出的作品图；封面为二维映屏合成。",
  "channel": "黄花鱼频道",
  "series": "02",
  "title": {
    "lines": [{"plain": "陶瓷杯建模", "highlight": "教程"}],
    "size": 122,
    "tracking": 9
  },
  "tools": "Codex × Blender",
  "subtitle": "从造型到釉面材质",
  "topics": ["杯体造型", "釉面材质", "灯光渲染"]
}
```

`topics` 恰好三项，通常每项 4–6 个汉字；`series` 是短编号。文字需与当前作品和实际讲解一致。可选 `fonts` 键为 `title`、`regular`、`bold`、`mono`，值为本机已授权字体文件路径，相对配置解析；不要分发私有字体。

## 长标题的明确边界

脚本不自动断句、不横向压缩字形、不省略文字。放不下时会以非零状态退出，并说明文字宽高和可用空间。

- 一行：标题区域 y=100–238，最大右界 x=1016；`title.size` 80–122，默认 122，`tracking` 默认 9px。单行通常适合约 7 个汉字，实际以字形测量为准；反色块额外保留左右各 24px 与块前 16px 间隔。
- 两行：显式写两项 `title.lines`；字号 68–84，默认 80，字距默认 4px。第一行 y=100–192、右界 x=1016；第二行 y=202–294、右界 x=780，避开右上小电视。工具条与副题依次下移至 y=310–380 和 y=394–430。
- 字距允许 0–12px。不同字体字形宽度会变，换字体后重新看全图与缩略图。工具条最多宽 716px，副题最多宽 716px；不适合把长段落塞进封面。

两行可参考 `assets/cover_example/two_line_example.json`。如果两行仍放不下，压缩文案或重新设计封面，不扩大标题区遮住作品。

## 输出与检查

- `cover.png`、`thumbnail.png`：封面与手机缩略预览。
- `text_layer.png`：透明原生文字/承载色块/底部肌理层。
- `background_composite.png`：本次实际使用的底图；artwork 模式下含二维映屏结果。
- `screen_detail.png`：artwork 模式的屏内细节及少量外缘，用于检查核心裁切与曲边贴合。
- `editable.svg`：内嵌底图和肌理，文字仍是可编辑原生文本。字体不内嵌，换设备后需装同款或重新选择字体。
- `render_report.json`：记录模式、来源说明、素材哈希、屏幕映射、实际字框和字体文件名；屏幕记录含 `artwork_crop`、最终 `effective_crop` 和 `mask_name`。报告内 `settings` 的相对路径仍以原输入配置所在目录为基准。

依次检查完整封面、屏内细节和 360px 缩略图：核心视觉足够大、轮廓可辨，花心或角色头部等关键部分没有被误裁；画面铺满有效内屏并贴合曲边，不出现缩小画面外的模糊补边或二次画框；教程类别、工具和三个教学点清楚，标题不压小电视，底栏不抢主体。不得残留示例花朵，也不能把二维映屏合成说成原生工程渲染。脚本不会自动判断主体或构图质量，仍需实际看图。
