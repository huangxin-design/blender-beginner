# 粉色装置｜制作过程摘要

早期实践资料，未作为当前 Skill v04 的效能验证。以下根据包内制作记录整理，没有原始逐字聊天；[六轮优化提示词](prompts.md) 属于事后重写，不是实际对话回复。

1. **建立底稿。** 根据参考制作粉色装置，保留褶柱、背板、珠子、悬球和前景小件，形成可编辑场景。
2. **升级原生效果。** 继续调整分层材质、灯光和调色，保存 `.blend`、原生 PNG 与线性 EXR。历史材质审计记录了 11 种含已连接 Mix 的在用材质。
3. **进行图片精修。** 以当时用户提供的图片为输入，加强色彩、体积、金属与绒面区别，记录实际英文提示词；这一步没有修改三维工程。
4. **保留实际差异。** 既有对照记录认为主要物件保留，但主体略放大、顶部留白减少、背景增加渐变，不能描述成只改曝光。
5. **明确交付关系。** 将终图、原生渲染与底稿分别归档。展示图中的最新精修效果仍属于图片层，不能用优化提示词反推这些效果已存在于工程中。
