# v002 · 灯罩改成绿色哑光陶瓷

**过程记录：** [制作回顾 · v002](../../conversation.md#v002)，无原始聊天摘录。

**输入：** `../v001/scene.blend`。

**演示修改需求：** 灯罩看着太塑料，改成绿色的哑光陶瓷。保留底座、支架、已有构图和画幅，把结果另存为新版本。

**需求到 Blender 的对应：**

| 日常表达 | 本版操作 |
| --- | --- |
| 还是原来的绿色 | 保留线性 RGB 约 `(0.16, 0.30, 0.23)`，不添加颜色斑点 |
| 不要那么塑料 | 金属度设为 0，使用较柔和的高光；粗糙度在 0.60–0.72 之间轻微变化 |
| 哑光陶瓷的细腻表面 | 程序噪声连接粗糙度与弱 Bump，凹凸强度 0.16，距离 0.00012 场景单位 |
| 其他地方不要动 | 复制共用材质，只赋给灯罩 `Lamp_Shade` 和顶盖 `Lamp_Top` |

**实际结果：** 新增 `Sage_Matte_Ceramic` 材质；底座继续使用原有 `Sage_Enamel`，金色部件继续使用 `Brushed_Brass`。几何、相机、灯光、画幅和原有材质保持。此例把顶盖视为灯罩外观的一部分。

**文件：** `scene.blend` 是修改后的工程，`preview.png` 是重新打开工程后渲染的小图，`edit.py` 接受显式输入与输出路径并拒绝覆盖已有输出。修改依赖程序节点，不需要联网或外部纹理。

**验收范围：** 工程可打开，只有灯罩组件切换新材质，原绿色和构图保持。整体高光变化可在预览中对照；细微肌理在 640 × 480 下不明显，不把小图当作高分辨率材质细节证明。

**运行记录：** 在 Blender 5.2.1 LTS 生成与检查；Cycles CPU、12 采样、640 × 480、AgX、静态第 1 帧。
