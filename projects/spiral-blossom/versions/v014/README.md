# V14 · 带光影的布线白模

从 [V13](../v013/scene.blend) 制作同位置、同镜头、同时长和同尺寸的白模版本。

实际改动：花瓣表面换成白色哑光材质，沿原始花瓣 UV 显示 10 列 × 22 行四边形网格；灯光色相中性化，保留位置与亮度关系、景深、光晕、运动模糊及茎杆细毛。布线是随形变工作的材质显示，不是偏移叠加的线框几何；曲线茎杆与绒毛保持纯白模。
