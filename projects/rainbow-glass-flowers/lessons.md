# 制作中保留下来的经验

1. **画面有遮挡，不代表模型可以相交。** 前后移动花朵时，既要看投影构图，也要检查三维空间中另一朵花的花瓣与花茎。第一轮前移仍有局部交叉，增加深度间隔后才通过完整检查。
2. **焦点跟着前景关系改变。** 右下花移到前景后，全景镜头改为对焦它；近景相机同步平移，保留取景关系。
3. **统一缩短动画时，不只改结束帧。** 花瓣形态键、花头、花茎和相机关键帧一并重定时，镜头切点也相应调整。
4. **“文件存在”不能证明帧有效。** 中断留下的三张 PNG 文件不是完整图像，编码前的尺寸和文件校验发现了问题。补渲后严格解码通过，才交付视频。
5. **留出可审查的范围。** 花瓣彼此的检查包含尖根；花瓣与花心、花托的必要接合单独记录。整数帧几何检查与实际画面复核相互补充。
