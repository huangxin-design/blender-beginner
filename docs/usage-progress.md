# v05：项目已记录用量与渲染进度

本版新增两个可执行工具，以及一个本地进度页面。它们按需启用；旧作品的 GitHub 源文件、提示词与精简对话继续独立维护。

## 项目 Token 怎么记录

可以直接告诉 Codex：

> 从现在开始记录这个 Blender 项目的 Token。使用明确的本项目会话来源，记录期间的制作、修改和诊断都算入。结束时告诉我记录范围、截至时间和还有哪些未结算。

工具读取一个明确指定的本地 Codex JSONL，支持 rollout 累计快照和 `codex exec --json` 逐轮用量。开始时建立基线，后续更新只计新增记录。用量更新本身不需要 API key，也不会发送模型请求。

总量是输入加输出。缓存输入包含在输入里，推理输出包含在输出里；两者单独展示但不额外累加。没有原始 usage 来源的旧工程保持“未记录”。当前正在生成的回复可能还没落盘，因此“请求结束记录”和“已观察到回合结束”分别显示。

这不是每个 `.blend` 的精确账单。同一轮讨论多个项目、其它会话、子代理和 fork 无法自动可靠合并；开始前的历史不导入，计数回退或日志替换会报错并保留原账本。订阅额度、费用和本地 GPU 耗时不由 Token 数反推。

用量账本只留在本地。净化摘要也可能含项目名和会话标识，公开前要另行检查；原始日志、账本不默认加入作品资料。详细命令和状态见 [Token 记录参考](../skills/blender-beginner/references/token-usage.md)。

## 渲染还要多久

可以告诉 Codex：

> 给这次渲染加上本地进度页面，保留工程设置，把输出放到新的目录。先显示阶段和已经用的时间，有实测依据再估计剩余范围。

执行器每秒左右更新本地 `progress.html`，浏览器定期刷新。无需启动常驻服务，也不需要每秒询问模型。页面显示本次执行的阶段、耗时、可靠帧计数，以及日志能提供的当前帧采样信息。

整体预估先等待首帧及三个后续完整帧，再用近期完整帧形成低可信经验范围。首帧初始化单独记录；后续慢帧仍计入。新的镜头或复杂度会改变耗时，估计可能上升，当前帧超出经验范围或进度过期时撤回 ETA。

| 状态 | 应如何理解 |
| --- | --- |
| 正在准备／收集完整帧 | 没有足够依据，整体剩余未知 |
| 当前帧采样预计剩余 | 只针对采样阶段，不包括所有保存和后续工作 |
| 成功输出帧 / 计划帧 | 由受控脚本验证主 PNG 非空后确认，不能直接数日志里的保存行 |
| 计划帧输出结束 | 仍在等待进程退出，画面还需验收 |
| 执行结束 | 进程正常退出，不保证作品符合需求 |
| 失败／超时／中断 | 已停止计时，读取日志并检查完整的中间文件 |
| 页面停止更新 | 暂无可信实时显示，读取本次执行记录；不要继续相信旧倒数 |

首版限定本次执行器启动的单场景 PNG 静图或明确帧序列，不监听用户已在 Blender 界面启动的渲染。原文件必须有适用的相机和 PNG 设置；多输出、活动视频序列、多视图等需专门流程，不能为显示进度静默关闭效果。单图或很短序列可能始终没有整体 ETA。

如果任务要交付视频，编码、软件／硬件解码逐帧对比和目标播放器检查仍单独执行。本版进度工具未自动实现这些视频验收。详见 [渲染进度参考](../skills/blender-beginner/references/render-progress.md)。

## 验证记录

2026-09-08，在 Windows x64、Python 3.10.6、Blender 5.2.1 上验证：

- Token：合成来源检查重复更新、等量的不同回合、晚到用量、结束边界、被中断的回合、缺失明细、计数回退、损坏／替换／截断、并发锁和原文不落盘。另用一个明确来源完成真实 begin / update / end，最终仍标待结算，没有宣称全项目精确用量。
- 真实渲染：Cycles CPU、64×64、4 samples，按 `-1,1,3,5,7,9` 输出六张 PNG；六张均可读、像素比较通过，实际查看代表帧，输入 `.blend` 的 SHA-256 保持一致。该简单静态测试验证执行链路，不验证复杂动画速度。
- ETA：真实 Cycles／EEVEE 日志及带时间戳的真实帧事件回放，检查首帧隔离、重复事件、采样归零、过期撤回、慢帧范围上升与终态。极短测试通过事件回放验证中间 ETA，不冒充长时动画实测。
- 渲染保护：已有输出目录、重复或越界帧、JPEG、多视图、缺相机、合成器额外输出、活动视频序列均拒绝。
- 执行器：原有执行入口、真实脚本异常、真实超时、无输出／半行输出／连续输出时的限时行为、已有日志目录保护，以及面板写入失败时仍保留渲染时间限制。
- 页面：桌面和手机尺寸的浏览器检查、空值、HTML 转义、过期数据与终态停止刷新。首页截图是明确标注的模拟数据。

公开的 [测试目录](../tests/README.md) 提供不依赖 Blender 的 Token 与进度回归检查。真实本机会话日志和测试输出不随仓库公开。

未验证：Mac／Linux 真机执行、复杂长动画、真实 GPU 长时估算误差、跨会话完整 Token 归属、其它 Codex 日志版本，以及这次没有新导出的视频。已有作品不作为 v05 功能效果证据。
