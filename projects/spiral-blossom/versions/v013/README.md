# V13 · 连续旋转，15 秒 / 60 fps

用户反馈上一版视频卡顿，希望增强甩出的冲击力，同时保持旋转生长和从上到下的长度、密度梯度。

实际改动：将分段急停的时间映射改成连续正速度积分；三次较宽的加速形成节奏，细丝保留延迟与弹性回摆。原生时间采样增至 60 fps，900 帧，结尾约 0.73 秒静止。保留长花瓣、绒毛、微距景深和光晕。
